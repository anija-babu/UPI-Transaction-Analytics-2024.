# 📂 Dataset Structure

The dataset contains the following columns:


## Description
### transaction_id: Unique identifier assigned to each transaction.
###  timestamp: Date and time when the transaction occurred.
###  transaction_type: Type of transaction, such as P2P (Person-to-Person) or P2M (Person-to-Merchant).
###  merchant_category: Category of the merchant involved in the transaction.
###  amount (INR): Transaction amount in Indian Rupees.
###  transaction_status: Current transaction status, such as SUCCESS or FAILED.
###  sender_age_group: Age group of the person initiating the transaction.
###  receiver_age_group: Age group of the person receiving the transaction.
###  sender_state: State from which the transaction was initiated.
###  sender_bank: Bank associated with the sender.
###  receiver_bank: Bank associated with the receiver.
###  device_type: Device used to initiate the transaction, such as Android or iOS.
###  network_type: Network connection used during the transaction, such as 4G or 5G.
###  fraud_flag: Indicator used to identify transactions flagged for potential fraud (0 or 1).
###  hour_of_day: Hour during which the transaction occurred.
###  day_of_week: Day of the week when the transaction occurred.
###  is_weekend: Indicator showing whether the transaction occurred on a weekend (0 or 1).
